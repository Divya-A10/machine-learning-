## Predicting Home Values in Iowa with Machine Learning ##
This project marks my first step into the world of machine learning. Using a dataset of home prices in Iowa, I built a simple regression model using a Decision Tree to predict the sale price of houses based on features such as lot size, year built, and number of rooms.

The steps involved include:

Loading and exploring the dataset using pandas
Selecting a prediction target (SalePrice) and key features
Training a DecisionTreeRegressor model with scikit-learn
Making predictions and reviewing model outputs
This project helped me understand the fundamentals of supervised learning, model fitting, and feature selection. It sets the foundation for more advanced projects in model evaluation, feature engineering, and optimization.
